利用規約

制定日：2026年10月26日

第1条（この規約について）

  1. この規約は、islands を使うすべての人（以下「利用者」）と運営チームとの間の約束です。
  2. 利用者は、登録またはログインをしたとき（画面の「続ける」などを押したとき）に、この規約に同意したものとします。
  3. この規約は、民法でいう「定型約款」（たくさんの人に同じ条件で使ってもらうための決まり）にあたります。
  4. 個人情報の扱いは、別に定める「プライバシーポリシー」のとおりです。あわせて読んでください。内容が食い違うときは、個人情報の扱いについてはプライバシーポリシーを優先します。

第2条（islands の目的）

islands は、「いま取り組んでいること」を短く投稿すると、似た投稿が「島」として地図に並ぶサービスです。コミュニティごとの地図を入り口にして、話の合う人を見つけ、仲間やつながりをつくることを目的にしています。この目的に沿って使ってください。

第3条（アカウント）

  1. islands は招待制です（招待された人だけが登録できます）。コミュニティの管理者からもらった招待リンクか QR コードから登録してください。ログインは、メールのパスコード、Google、LINE のいずれかでできます。
  2. 利用者は、名前やプロフィールなどに、自分についての正しい情報を入力してください。
  3. ログインに使うメール、Google、LINE のアカウントは、利用者が自分で責任をもって管理してください。ほかの人に使わせたり、貸したり、譲ったりしてはいけません。
  4. アカウントが不正に使われたと気づいたときは、すぐに第16条の連絡先に知らせてください。
  5. 18歳未満の人は、保護者の方とこの規約の内容を確かめたうえで使ってください。運営チームが保護者の同意を確かめることはありません（プライバシーポリシーと同じ扱いです）。
  6. 1人で複数のアカウントを作らないでください。1つのアカウントで、複数のコミュニティに参加できます。

第4条（コミュニティと招待）

  1. コミュニティは招待制で、それぞれに自分の地図があります。
  2. 招待リンクや QR コードを作れるのは、そのコミュニティの管理者だけです。管理者は、リンクの有効期限を選べ、いつでもリンクを止められます。止めたリンクは、それ以降使えません。
  3. 管理者は、招待リンクを作ること、期限を決めること、止めることのほか、メンバーをコミュニティから外すことがあります。外されたメンバーは、そのコミュニティの投稿などを見られなくなります。それまでに書いた投稿の扱いは、自分で抜けたとき（第11条1項）と同じです。管理者であっても、この規約を守る必要があります。
  4. 招待リンクや QR コードは、招待したい相手にだけ届けてください。次のことはしないでください。
    • SNS や掲示板など、誰でも見られる場所に載せること
    • 売ったり、買ったりすること
    • 不特定多数の人に配ること
  5. 招待リンクを使うと、リンクが何回使われたかが記録されます。
  6. コミュニティの投稿、コメント、反応（だれが「参加」したかを含みます）は、そのコミュニティのメンバーだけが見られます。ただし、次のものは、コミュニティに入っていない人や、ログインしていない人を含め、だれでも見られることがあります。くわしくはプライバシーポリシーの「3. ほかの人が見られる情報」を見てください。
    • プロフィール（名前、所属、自己紹介、リンク、アイコンや写真、話題、目標、探していること、提供できること）
    • 投稿などに付けた画像（画像のアドレスを知っている人は開けます）
    メンバーは、見た内容を保存したり、ほかの人に伝えたりできてしまうことにも気をつけてください。DM の中身は、その2人だけが見られます（第6条6項）。

第5条（投稿・コメント・メッセージ）

  1. 投稿、コメント、画像、プロフィール、メッセージ（以下「投稿など」）の権利は、書いた人（作った人）のものです。運営チームがその権利をもらうことはありません。
  2. ただし、islands を動かすために、運営チームは投稿などを、次の範囲で無償で使えるものとします。
    • islands の画面に表示すること（第4条6項の範囲で）
    • 保存すること、バックアップをとること
    • 島や地図をつくるために、文章の特徴を数値にして計算に使うこと
    • 運営を任せている事業者（Supabase、Google など）に、運営に必要な範囲で扱わせること
  3. 島づくりや島の名前づけのために、投稿の文章とプロフィールの一部（関心のあること、目標、探していること、提供できること）は、運営チームのサーバーから Google の Gemini API に送られます。送る内容と、送らない内容（表示名、所属、メールアドレス、画像、リンクなど）は、プライバシーポリシーの「4-3. Gemini API」に書いてあるとおりです。利用者は、これに同意して使うものとします。
  4. 投稿などの内容は、利用者自身の責任で書いてください。他人の著作権や肖像権などを侵害するものを載せてはいけません。
  5. 本名、勤務先、連絡先、住所、病気や信仰など、知られたくないことは書かないでください。第4条6項のとおり、プロフィールはだれでも見られることがあり、投稿はコミュニティのメンバーに保存されたり広められたりすることがあります。
  6. 入力できる文字数などの上限は、画面に表示されます。上限は、予告なく変わることがあります。

第6条（「もっと話してみたい」とメッセージ）

  1. 相手のプロフィールにある「もっと話してみたい」ボタンを押しても、押した人の名前は相手に伝えません。ただし、相手には「誰かが、あなたともっと話してみたいと言っています」という、名前の出ない通知が届くことがあります。同じ人から同じ相手への通知は、14日に1回までです。人数の少ないコミュニティでは、押した人を想像されることがあります。
  2. 押した記録は、自分で取り消すか、おたがいに押して DM が開くまで残ります。何日たってからでも、相手が押せば DM が開きます。
  3. おたがいに「もっと話してみたい」を押したときだけ、1対1のメッセージ（DM）が開きます。今のところ、同じ「参加者募集中」の投稿に「参加」した人どうしが対象です。
  4. DM では、相手をブロックできます。ブロックしたことは、相手に知らされません。ブロックすると、どちらの向きでもメッセージを送れなくなります。
  5. DM でも、第8条の禁止事項は同じように守ってください。相手が嫌がっているのに、しつこく連絡し続けることはしないでください。
  6. 運営チームは、DM の内容を見ません。ただし、次のときは除きます。
    • 当事者の一方が、内容を示して相談してきたとき
    • 法令にもとづくとき
    • 人の生命や身体を守るために、急ぎ必要なとき
    • 障害への対応に、最小限必要なとき
  7. DM で困ったときは、相手をブロックするか、第16条の連絡先に知らせてください。
  8. コミュニティから抜けても、そこで始まった DM はそのまま続きます。やめたいときは、相手をブロックしてください。

第7条（反応・コメント・通知）

  1. 投稿には、コメントや反応（「いいね」「手伝えるかも」「参加」）ができます。
  2. コメントや反応を送ると、相手に通知が届くことがあります。通知の設定は、利用者が変えられます。ウェブプッシュ通知を使うかどうかは、利用者が選べます。

第8条（禁止事項）

利用者は、次のことをしてはいけません。

  1. 法令や公序良俗（社会の常識）に反すること
  2. 嫌がらせ、誹謗中傷、脅しなど、他人を傷つけたり困らせたりすること
  3. 他人や、団体・組織になりすますこと
  4. 他人の個人情報（名前、連絡先、住所、写真など）を、本人の同意なく載せたり伝えたりすること
  5. 運営チームや、そのコミュニティの管理者の許可なく、営業、宣伝、勧誘（商品やサービスの売り込み、ほかのサービスへの誘いなど）をすること。イベントの告知や参加者の募集は、許可がなくてもできます。DM では、相手が望んでいない宣伝や勧誘をしないでください
  6. マルチ商法やねずみ講への勧誘、宗教の勧誘をすること（許可があってもできません）
  7. 同じ内容をくり返し送るなどのスパム行為
  8. 不正アクセス、サービスの妨害、仕組みの悪用など、他の利用者や運営チームの迷惑になる使い方
  9. わいせつな内容や、暴力的・残酷な内容を載せること
  10. 人種、国籍、性別、性的指向、障害、年齢、出身などによる差別や、差別をあおること
  11. 他人のアカウントを使うこと
  12. 招待リンクや QR コードを、売ったり買ったり、不特定多数に公開したりすること（第4条のとおり）
  13. 他人の権利（著作権、肖像権、プライバシーなど）を侵害すること
  14. 上のほか、前各号に準じる行為で、ほかの利用者の安全や islands の運営を害するもの

第9条（違反したときの対応）

  1. 利用者が規約に違反した、または違反する可能性が高いと運営チームが判断したときは、運営チームは、違反の程度に見合った範囲で、次の対応をとることがあります。
    • 投稿などの削除や、非表示にすること
    • 一部の機能を使えなくすること
    • アカウントの利用停止や、削除
  2. 他の利用者に危険が及ぶなど、急いで対応する必要があるときは、事前に連絡せずに対応することがあります。
  3. 対応の理由は、連絡することがあります。ただし、個別のやりとりには応じられないことがあります。
  4. 運営チームの責任については、第13条のとおりとします。

第10条（通報）

  1. 規約に反すると思う投稿やコメントを見つけたら、画面の通報の機能で運営チームに知らせてください。理由は500字まで書けます。DM で困ったときは、第6条7項のとおり、ブロックするか、第16条の連絡先に知らせてください。
  2. 通報したことは、通報された相手には伝わりません。通報の内容を見られるのは、運営チームだけです。
  3. 通報された内容は、運営チームが確かめて、第9条の対応をするかどうかを決めます。必ず対応するとは限りません。
  4. 人をおとしいれるために、うその通報をしてはいけません。

第11条（脱退・退会とデータ）

  1. コミュニティからは、自分でいつでも抜けられます。ただし、そのコミュニティの管理者が自分1人だけのときは抜けられません。抜けても、それまでの投稿は消えず、そのコミュニティのメンバーには見えたままです。自分の投稿は、抜けたあとも自分のページで見られます。消したいときは、自分で消すか、第16条の連絡先に連絡してください。
  2. 今のところ、islands の画面には退会（アカウントの削除）の機能がありません。退会したいときは、第16条の連絡先に連絡してください。
  3. 運営チームは、本人であることを確かめたうえで、アカウントと投稿などを削除します。削除の範囲と、削除のあとも残ることがある情報は、プライバシーポリシーの「7. 保存期間と削除」のとおりです。削除した投稿についていたほかの人のコメントや反応など、残ることがあるものがあります。
  4. 削除したデータは、バックアップにしばらく残ることがあります。
  5. 退会しても、DM で送ったメッセージは相手の画面に残ります。送った人は「退会した人」と表示され、その DM には新しいメッセージを送れなくなります。
  6. 退会しても、ほかの人に保存された内容などは消えないことがあります。

第12条（サービスの変更・停止）

  1. islands は、小さく試しながら育てている途中のサービスです。運営チームは、機能や画面を、予告なく変えたり、追加したり、やめたりすることがあります。
  2. 次のときは、事前の連絡なく、一時的にサービスを止めることがあります。
    • 点検や、更新作業のとき
    • 障害や、地震や停電などの災害のとき
    • 外部のサービス（Supabase、Google、LINE など）に問題が起きたとき
  3. サービスをやめるときは、できるかぎり事前に知らせます。
  4. 今のところ、islands は無料で使えます。将来、有料のプランを作ることがあります。その場合は、事前に内容と金額を知らせ、同意した人だけが使う形にします。無料の機能を、知らせなく有料にすることはしません。

第13条（免責）

  1. 運営チームは、islands の内容や機能が、正確・安全・完全であることや、特別な目的に合うことを保証しません。
  2. 利用者どうしのやりとり（DM、会うこと、参加するイベントなど）は、利用者自身の責任で行ってください。利用者どうしのトラブルには、運営チームは原則として関わりません。
  3. 運営チームの故意（わざと）または重大な過失（重い不注意）による損害は、運営チームが責任を負います。
  4. 運営チームの軽い過失（重大でない不注意）による損害は、その損害のうち、通常生じる範囲に限って、運営チームが責任を負います。
  5. この規約のうち法律で無効とされる部分は、その範囲では適用しません。

第14条（規約の変更）

  1. 運営チームは、次のどちらかにあたるときは、この規約を変えることがあります。
    • 変更が利用者の一般の利益に合うとき
    • 変更が、契約をした目的に反せず、変更の必要性や内容などから見て合理的なとき
  2. 変更するときは、変更後の内容と、効力が生じる日（施行日）を、施行日より相当の期間前（大きな変更は少なくとも2週間前）までに、islands の画面やウェブサイト上で知らせます。
  3. 施行日のあとも islands を使い続けた利用者は、変更に同意したものとします。同意できないときは、第11条の手順で退会できます。

第15条（権利の譲渡など）

利用者は、この規約で得た権利や義務を、運営チームの同意なく、他の人に譲ったり担保にしたりしてはいけません。

第17条（準拠法・裁判所）

  1. この規約は、日本の法律に従って解釈します。
  2. islands や、この規約について争いが起きたときは、まず話し合いで解決をめざします。それでも解決しないときは、運営チームの所在地を管轄する日本の裁判所を、第一審の専属的合意管轄裁判所とします。
