1. 取得する情報

運営チームが取得するのは、islands の機能に必要な情報だけです。

1-1. アカウントの情報

  • メールアドレス（パスコードの送り先、またはログインに使うもの）
  • 名前（表示名。必須、16字まで）
  • 所属（任意、32字まで）
  • アイコン写真（任意）
  • 自己紹介（300字まで）、リンク（200字まで）、関心のあること、目標、探していること、提供できること（いずれも任意）
  • 通知の設定（通知の種類ごとのオン・オフ）

年齢、生年月日、電話番号、住所は聞きません。パスワードも使いません。

1-2. ログインのときに受け取る情報

islands には、次のログイン方法があります。

  • メールのパスコード（メールに届く、一度だけ使う数字のコード）
  • Google ログイン（受け取るのは、ログイン用の基本情報〈openid・email・profile の範囲〉だけ）
  • LINE ログイン（受け取るのは、ログイン用の基本情報〈openid・profile の範囲〉だけ）

メールアドレスでパスコードを請求すると、プロフィールの登録を終えなくても、そのメールアドレスはログインの仕組み（Supabase）に保存されます。

LINE ログインでは、メールアドレスを受け取りません。Google ログインで受け取るメールアドレスは、本人の識別とアカウントの作成に使います。

islands のプログラムが使うのは、ログインで受け取る情報のうち、利用者の ID、メールアドレス、ログイン方法（Google・LINE・メール）だけです。Google や LINE の名前や写真を、表示名やアイコンに自動で使うことはしません。名前は、登録画面でご自身で入力します。

ただし、ログインの仕組みを提供する Supabase（第4章）には、Google や LINE が渡す情報（メールアドレス、名前、プロフィール画像、それぞれのサービスでの利用者の番号など）が保管されることがあります。

1-3. 投稿などの内容

  • 投稿の本文（60字まで）、タグ、お題の種類、熱量、画像、募集の申込期限や先着人数
  • 投稿から取り出した語（名詞など）。投稿と一緒に公開されます
  • コメント、返信
  • 反応（いいね・手伝えるかも・参加）
  • 通報の内容（理由は500字まで）
  • 投稿や、プロフィールの「関心のあること」「目標」「探していること」「提供できること」をもとに計算した、地図の上の位置と、文章の特徴を表す数値（ベクトル）。数値は運営チームのサーバーだけが扱い、ほかの人には見えません

1-4. 端末に保存する情報

お使いのブラウザの localStorage（ブラウザの中にある、小さなデータの置き場所）に、次のものを保存します。

  • ログインの状態を保つための情報（ログイン用の印〈トークン〉、利用者の ID、メールアドレス、ログイン方法、有効期限）
  • 音・振動などの設定
  • 通知をオフにした印
  • 読んだ投稿の記録、見た変化の記録、使い方の案内の進み具合
  • ログインしていない人の閲覧を数えるための、ランダムな識別の番号

1-5. 通知とアクセスに関する記録

  • 通知の記録（だれの、どの投稿やコメントへの、反応・返信・似た人・島の変化などの通知か。作った日時と読んだ日時を含みます）。通知は本人だけが読めます
  • 通知を許可した端末の情報（通知の宛先の情報と、ブラウザの種類を表す User-Agent の先頭300字）
  • 最後に利用した日時
  • 投稿を開いた人の記録（ログイン中は利用者の ID、ログインしていないときは上のランダムな番号）。投稿者本人には、人数だけを知らせます
  • Cloud Run（islands のサーバーを動かす Google のサービス）が自動で残すアクセスの記録。IP アドレス（インターネット上の住所のようなもの）などが含まれます
  • Supabase が自動で残す通信の記録。地図や投稿を見る通信、ログイン、画像の表示は、ブラウザから Supabase に直接届くため、IP アドレスなどが含まれます

islands の自前のプログラムは、IP アドレスを保存しません。ただし、上の2つの記録には含まれます。

1-6. コミュニティ、「もっと話してみたい」、DM

  • どのコミュニティに入っているか、そのコミュニティの管理者かどうか、入った日時
  • 招待リンクの情報（作った管理者、有効期限、止めた日時、使われた回数）と、どの招待リンクから登録したか
  • 「もっと話してみたい」を、だれがだれに押したか、押した日時と、きっかけになった「参加者募集中」の投稿（ある場合）
  • 名前の出ない通知を、だれからだれに送ったかの記録（同じ人から同じ相手への通知を14日に1回までにするため）
  • 「もっと話してみたい」が押された数と、DM が開いた数の、日ごとの合計（だれのものかは記録しません）
  • 「もっと話してみたい」を1日に押した人数（1日に押せる人数の上限を確かめるため）
  • DM のメッセージ（1通1000字まで）、送った日時、DM が開いたきっかけの投稿
  • DM の部屋を最後に開いた日時（相手の画面に「既読」と表示するため。部屋の2人だけが使い、ブロック中は新しく記録しません）
  • DM のメッセージへの絵文字の反応（だれが、どのメッセージに、どの反応を付けたか。部屋の2人だけが見られます）
  • ブロックの記録（だれがだれをブロックしたか）

2. 利用目的

取得した情報は、次の目的に使います。

  • アカウントの作成、ログイン、本人の識別
  • 投稿・地図・島の表示、似た投稿やプロフィールの近さの計算
  • 反応、コメント、参加者の募集、通知の提供
  • コミュニティと招待の管理（だれがどのコミュニティの投稿を見られるかの判断を含みます）
  • 「もっと話してみたい」でおたがいに押したかどうかの判定と、DM・ブロックの提供
  • 機能の見直しのための集計（「もっと話してみたい」が押された数、DM が開いた数）
  • 島の位置や種類の判定、島の名前づけ
  • 通報への対応、不正な利用やトラブルの防止
  • 不具合の調査、サービスの安全な運営
  • 問い合わせへの対応

これ以外の目的には使いません。目的を変えるときは、このページでお知らせします。

3. ほかの人が見られる情報

3-1. コミュニティのメンバーだけが見られる情報

islands のコミュニティは招待制です。次の情報は、そのコミュニティのメンバーだけが見られます。

  • そのコミュニティの地図と島、投稿（本文、タグ、画像、熱量、お題の種類、募集の申込期限・先着人数、投稿から取り出した語、投稿日時、反応の数）
  • コメント
  • だれがどの投稿に「いいね」「手伝えるかも」「参加」をしたか（参加者の一覧を含みます）
  • どの投稿者がどの島にいるか（島ごとの投稿者の一覧）
  • そのコミュニティの名前と、だれが入っているか、だれが管理者か

ほかの人のプロフィールを開いたときに見える投稿も、同じコミュニティの投稿だけです。コミュニティから抜けた人は、そのコミュニティの投稿などを見られなくなります（自分の投稿は、自分のページで見られます）。

3-2. だれでも見られることがある情報

次の情報は、コミュニティに入っていない人や、ログインしていない人を含め、インターネット上のだれでも見られることがあります。

  • プロフィール（表示名、所属、自己紹介、リンク、アイコン、関心のあること、目標、探していること、提供できること、登録日）
  • 投稿やアイコンの画像。画像は公開の保管場所に置かれるため、画像の URL を知っている人は見られます

3-3. DM と「もっと話してみたい」

DM のメッセージは、その DM の2人だけが読めます。運営チームは、DM の内容を見ません。ただし、次のときは除きます。

  • 当事者の一方が、内容を示して相談してきたとき
  • 法令にもとづくとき
  • 人の生命や身体を守るために、急ぎ必要なとき
  • 障害への対応に、最小限必要なとき

「もっと話してみたい」をだれがだれに押したかは、押した本人のほかには見えません。押された人には、名前の出ない通知が届くことがあります。おたがいに押したときだけ、2人に相手の名前が知らされ、DM が開きます。ブロックしたことも、相手には知らされません。

3-4. ほかの人には見えない情報

メールアドレス、通報した人、投稿を開いた人の一覧、文章の特徴を表す数値、招待リンクの使われ方の記録は、ほかの人には見えません（招待リンクの使われた回数は、そのコミュニティの管理者が見られます）。

投稿やプロフィールには、本名、勤務先、連絡先、住所、病気や信仰など、ほかの人に知られたくないことを書かないでください。コミュニティの中で見せた内容も、メンバーに保存されたり、広められたりするおそれがあります。

4. 外部のサービスの利用

islands は、次の外部のサービスを使っています。それぞれに、必要な範囲で情報を送ります。

4-1. Supabase（Supabase, Inc.、アメリカ合衆国）

データベース、ログイン（認証）、画像の保存に使います。アカウントの情報、投稿、コメント、反応、通知の情報、コミュニティと招待の情報、DM のメッセージ、画像、メールアドレスなどを保管します。データは、日本（東京）のサーバーに保存しています。

ブラウザは、地図・投稿・プロフィール・画像の表示とログインの確認のために、Supabase に直接つながります。そのため、見ただけの人の IP アドレスなども Supabase に届きます。

4-2. Google Cloud（Google LLC、アメリカ合衆国）

islands のサーバーを動かす Cloud Run と、地図のデータの保存に使います。サーバーと地図のデータは、日本（東京）に置いています。

4-3. Gemini API（Google LLC、アメリカ合衆国）

文章を数値（ベクトル）に変えて、似た投稿を探すために使います。運営チームのサーバーから、次の内容を送ります。

  • 投稿の本文、またはそこから取り出した語（投稿の保存時・編集時と、投稿前のプレビューのとき）
  • プロフィールの「関心のあること」「目標」「探していること」「提供できること」（保存時）
  • 島の名前と、その島の投稿から取り出した語（最大8語）。島の位置や種類を決めるために、地図を更新するときに送ります
  • 島の名前づけのための、島にある投稿の本文（1件80字まで、最大30件）。この名前づけの機能を使っているときだけ送ります
  • 投稿する前に、文章の話題がいくつ入っているかを確かめるための、書いている途中の本文（「次へ」を押したとき）。本文だけを送り、結果は保存しません

表示名、所属、メールアドレス、画像、リンクは送りません。ブラウザから Gemini API に直接送ることもありません。

運営チームは、有料の Gemini API を使っています。Google の Gemini API の追加利用規約では、有料のサービスで送った内容は Google の製品の改善には使われないとされています。ただし、不正利用の防止のために、一定の期間保管されることがあります。規約は変わることがあります。

4-4. Google ログイン、LINE ログイン

ログインの確認のために、Google（Google LLC、アメリカ合衆国）と LINE（LINEヤフー株式会社、日本）との間で、ログインの操作に必要な情報がやりとりされます。

4-5. プッシュ通知の配信サービス

通知を許可すると、お使いのブラウザを作っている会社の配信サービス（Google、Mozilla、Apple、Microsoft のいずれか）を通して通知を送ります。通知の中身は、お使いの端末の鍵で暗号化して送るので、配信サービスは中身を読めません。

4-6. メールの配信

パスコードのメールは、ログインの仕組み（Supabase）を通して送ります。

5. 第三者への提供・委託・外国の事業者

5-1. 第三者への提供

運営チームは、次の場合を除き、ご本人の同意なく、個人情報を第三者に渡しません。

  • 法令にもとづく場合
  • 人の生命、身体、財産を守るために必要で、ご本人の同意を得ることが難しい場合
  • そのほか、法令で認められている場合

広告の事業者や、データを売り買いする事業者に、情報を渡すことはありません。

5-2. 委託

第4章の事業者には、サービスの運営に必要な範囲で、情報の取扱いを任せています（委託）。運営チームは、委託先が情報を適切に扱うよう、必要な監督を行います。

5-3. 外国の事業者への移転

次の事業者は、アメリカ合衆国の会社です。

  • Supabase, Inc.（データの保存先は日本〈東京〉）
  • Google LLC（Cloud Run と地図のデータは日本〈東京〉。Gemini API は処理する場所を利用者側で指定できないため、処理する国を特定できません。日本の外で処理されることがあります）
  • プッシュ通知の配信サービスの会社（Google LLC、Mozilla Corporation、Apple Inc.、Microsoft Corporation）

アメリカには、日本の個人情報保護法にあたる、国全体に共通する包括的な法律はありません。分野ごとの法律や、州ごとの法律（カリフォルニア州消費者プライバシー法など）があります。くわしくは、個人情報保護委員会の「外国制度（アメリカ合衆国）」をご覧ください。

Supabase と Google は、利用規約やデータ処理の取り決めで、決められた目的の範囲だけで情報を扱うこと、安全管理、再委託先の監督、漏えいなどが起きたときの通知などを定めています。セキュリティについて、第三者機関の認証（SOC 2 など）も受けています。運営チームが確かめた範囲では、これらは OECD プライバシーガイドラインの8原則に対応する措置です。

プッシュ通知の配信サービスには、暗号化された通知と宛先の情報だけが届き、通知の中身は読めません。

islands に登録またはログインすると、この 5-3 に書いた外国の事業者への個人データの移転に、同意いただいたことになります。同意いただけない場合は、登録・ログインをしないでください。

6. Google のユーザーデータの扱い

islands が Google から受け取るのは、ログインに必要な情報（openid・email・profile の範囲）だけです。具体的には、メールアドレス、名前、プロフィール画像、Google の利用者を表す番号です。Gmail やドライブなど、Google のほかのサービスの情報には、アクセスしません。

islands による、Google の API から受け取った情報の利用とほかのアプリへの移転は、Google API Services User Data Policy（Limited Use の要件を含みます）に従います。

  • 使い道：ログイン、アカウントの作成、本人の識別のためだけに使います。islands のプログラムが使うのは、このうち利用者の ID とメールアドレスです。
  • 保存：取扱いを任せている Supabase に保存します。ログインの状態を保つため、お使いのブラウザにもメールアドレスなどを保存します。
  • 共有：取扱いを任せている Supabase と、法令にもとづく場合を除き、だれにも渡しません。広告には使わず、売りません。
  • 削除：第10章の方法で、削除を依頼できます。

7. 保存期間と削除

7-1. 保存期間

投稿やアカウントの情報は、削除のご依頼があるまで保存します。一定の期間で自動的に消す仕組みは、今のところありません。使う必要がなくなった情報は、遅滞なく消すよう努めます。

「もっと話してみたい」を押した記録は、ご自身で取り消すか、おたがいに押して DM が開くまで保存します（DM が開くと消します）。名前の出ない通知を送った記録は、14日たつと消します。1日に押した人数の記録は、2日たつと消します。

7-2. 投稿やコメントを削除したとき

投稿やコメントを画面から削除すると、ほかの人には見えなくなります。ただし、データベースには、削除の印をつけたデータが残ります（論理削除といいます）。

削除した投稿に付いていたコメントや反応のデータは、消えずに残ります。画面には出ませんが、技術的な方法を使えば、だれでも取得できる状態です。

投稿を削除したり、画像を外したりしても、保存された画像のファイルが残ることがあります。その場合、画像の URL を知っている人は、見られる可能性があります。

反応（いいね・手伝えるかも・参加）は、ご自身で取り消すと、データも削除されます。データを完全に消したい場合は、第10章の方法でご連絡ください。

7-3. 退会（アカウントの削除）

islands の画面には、今のところ退会の機能がありません。退会したい場合は、第13章の連絡先にご連絡ください。

ご本人であることを確かめたうえで、アカウント、投稿、コメント、反応、通知、通知の設定、コミュニティへの所属、「もっと話してみたい」の記録、ブロックの記録を削除します。アップロードされた画像のファイルも、運営チームが確かめて削除します。

次のものは、残ることがあります。

  • DM で相手に送ったメッセージ（相手の画面に残ります。送った人は「退会した人」と表示され、新しいメッセージは届かなくなります）
  • 島の移り変わりの記録など、個人を特定できない形の記録
  • 法令の定めや、不正の調査のために必要な情報（必要な間だけ）
  • ほかの人の投稿に残る、あなたの閲覧の記録
  • バックアップに残るデータ

7-4. バックアップ

運営チームは、障害や作業のミスに備えて、必要なときにデータの複製（バックアップ）をとり、運営チームが管理する端末などに保存します。Supabase も、仕組みとしてバックアップをとることがあります。削除したデータが、バックアップにしばらく残ることがあります。

8. 安全管理のための取り組み

  • 通信の暗号化（HTTPS）
  • データベースのアクセス権限の制限（本人以外が見てはいけない情報は、ブラウザから読めないようにしています）
  • 文章の特徴を表す数値や通報の情報は、運営チームのサーバーだけが扱います
  • パスワードを預からない仕組み（メールのパスコード、Google、LINE のログイン）
  • 秘密の情報の管理（サーバーの鍵などは、専用の管理の仕組みに保管します）
  • 扱える人の限定（データの管理の画面や鍵を使えるのは、運営チームのメンバーだけです）
  • バックアップの保管（運営チームが管理する端末に置き、ほかの人が触れられないようにします）
  • 外国の制度の把握：5-3 のとおり、アメリカ合衆国の事業者に取扱いを任せています。アメリカの個人情報の保護の制度を、個人情報保護委員会が公表している情報で確かめたうえで、必要な安全管理を行います

安全管理の細かい内容は、お問い合わせに応じてお答えします。

9. Cookie などの扱い

islands のプログラムは、Cookie（ブラウザに保存される小さなデータ）を使いません。ログインの状態などは、1-4 のとおり localStorage に保存します。ブラウザの設定で localStorage を消すと、ログインが解除されます。

通知を許可すると、通知を受け取るための小さなプログラム（Service Worker）がブラウザに登録されます。画面や投稿の内容は保存しません。

Google アナリティクスなどのアクセス解析のツールや、広告のためのタグは使っていません。

開発者向けの解説ページ（/docs）を開くと、表示のために Google Fonts（Google LLC）と jsDelivr から、文字のデータやプログラムを読み込みます。このとき、お使いの端末の IP アドレス、ブラウザの種類、開いたページなどが、これらの事業者に送られます。
